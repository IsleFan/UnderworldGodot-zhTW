UnderworldGodot-zhTW 安裝說明（Windows）
==========================================

《Ultima Underworld》（創世紀地下世界）的 Godot 重製引擎，含繁體中文化。
本程式不含遊戲資料，需要你自己合法擁有的遊戲檔案（例如 GOG 版）。

系統需求
--------
- Windows 10 或 11，64 位元（x64）
- 支援 Vulkan 的顯示卡與驅動程式（近年的顯示卡與內建顯示晶片都支援）
- 不需要安裝 .NET、Godot 或其他軟體，執行環境已經包含在程式裡

需要特別注意的三件事
--------------------
1. 遊戲資料要自備：本程式只是引擎，需要你合法擁有的《Ultima Underworld》遊戲檔案（例如 GOG 版）。
2. 第一次打開時 Windows 可能出現藍色的「Windows 已保護您的電腦」：本程式沒有數位簽章，
   按「其他資訊」>「仍要執行」即可。
3. 只有 MT-32 配樂（選用）需要另外安裝「Microsoft Visual C++ 可轉散發套件」，而且要自備 MT-32 ROM。
   一鍵安裝會自動裝好這個套件；沒裝時選 MT-32 會自動改用 OPL 配樂，其他功能完全不受影響。


快速安裝（一鍵）
----------------

先在 GOG 安裝好《Ultima Underworld》或《Ultima Underworld II》（見「二、準備遊戲檔案」步驟 1；
兩者附的是同一張遊戲光碟映像，裝其中一個就能取出兩代），然後：

1. 把下載的 zip 解壓縮到你想放的位置，例如 C:\Games\UnderworldGodot-zhTW。
2. 在解壓縮出來的資料夾裡按兩下 INSTALL.bat。
   出現藍色的「Windows 已保護您的電腦」時，按「其他資訊」>「仍要執行」。
3. 安裝程式會自動完成：
   - 解除下載封鎖，之後打開 Underworld.exe 不會再被擋
   - 沒有 Visual C++ 可轉散發套件時自動下載安裝（會跳出系統管理員確認，請按「是」）
   - 從 GOG 版取出遊戲檔案到 %USERPROFILE%\Games\UWGOG\UW1、UW2，並取消唯讀
     （缺哪一代補哪一代；已經存在的資料夾不會被覆蓋，裡面的存檔不受影響）
   - 把遊戲目錄寫進設定，語言設為繁體中文
   - 打開遊戲
4. 如果 GOG 版裝在特別的位置而找不到，可以在命令提示字元指定：
     INSTALL.bat -GogDir "D:\你的GOG安裝資料夾"
   遊戲檔案要放在別處時加上 -GamesDir "D:\你想放的資料夾"。

一鍵安裝失敗時，照下面的手動步驟處理。以下各節也說明了一鍵安裝做的每件事。


一、安裝需要的軟體
------------------

1. Microsoft Visual C++ 可轉散發套件（建議安裝）

   用途：MT-32 配樂模式（mt32、cm32l）需要它。沒有安裝時，選 MT-32 會自動改用 OPL 配樂，
   其他模式不受影響。許多電腦已經裝過，重複安裝也沒有關係。

   a. 用瀏覽器下載微軟官方安裝程式（x64 版）：
      https://aka.ms/vs/17/release/vc_redist.x64.exe
   b. 執行下載的 vc_redist.x64.exe，勾選同意授權條款，按「安裝」。
   c. 安裝完成後不需要重新開機。

2. 顯示卡驅動程式

   如果遊戲畫面全黑或無法啟動，請到顯示卡廠商網站（NVIDIA、AMD、Intel）更新到最新驅動程式。


二、準備遊戲檔案
----------------

需要的是一個同時含有 UW.EXE、DATA 資料夾、SOUND 資料夾的「遊戲目錄」。

1. 在 GOG（https://www.gog.com）購買並安裝《Ultima Underworld 1+2》。
   用 GOG Galaxy 或離線安裝程式都可以。

2. 打開遊戲的安裝資料夾（GOG Galaxy：在遊戲頁面按「管理安裝 > 顯示資料夾」）。

   - 如果資料夾裡已經有 UW.EXE、DATA、SOUND，直接用這個資料夾，跳到步驟 4。
   - GOG 版通常把遊戲包在一個叫 game.gog 的光碟映像檔裡，請繼續步驟 3。

3. 從光碟映像取出遊戲檔案：
   a. 把 game.gog 複製一份到桌面，改名成 game.iso。
      （看不到副檔名時：檔案總管 > 檢視 > 勾選「副檔名」。）
   b. 在 game.iso 上按兩下，Windows 會把它掛載成一個光碟機。
   c. 光碟裡的 UW 資料夾是第一代，UW2 資料夾是第二代。
      把它們複製到你想放的位置，例如：
        C:\Games\UWGOG\UW1   （複製 UW 資料夾的內容）
        C:\Games\UWGOG\UW2   （複製 UW2 資料夾的內容）
   d. 複製完成後，在檔案總管的光碟機上按右鍵 > 「退出」。
   e. 從光碟複製出來的檔案可能是唯讀的，這樣會沒辦法存檔：
      在 UW1（及 UW2）資料夾上按右鍵 > 內容 > 取消勾選「唯讀」> 套用 >
      選「將變更套用至此資料夾、子資料夾及檔案」> 確定。

4. 記下遊戲目錄的位置，下面會用到。


三、安裝本程式
--------------

1. 把下載的 zip 解壓縮到你想放的位置，例如 C:\Games\UnderworldGodot-zhTW。
   請整個資料夾一起保留：Underworld.exe 旁邊的 Underworld.pck、data_Underworld_windows_x86_64、
   i18n、soundfonts 都是程式需要的檔案。
2. 不需要執行安裝程式，也不會寫入系統資料夾。


四、第一次執行
--------------

1. 按兩下 Underworld.exe。
2. 如果出現藍色的「Windows 已保護您的電腦」視窗（因為本程式沒有數位簽章）：
   按「其他資訊」> 「仍要執行」。
3. 進入啟動畫面後：
   a. 右邊的「Language」選「繁體中文」，畫面會換成中文。
   b. 在左邊 UW1 卡片按「瀏覽…」，選有 UW.EXE 的遊戲目錄。
      下方出現綠色的「已找到遊戲」就完成了；紅字表示目錄不對。
      （UW2 同樣做法，在 UW2 卡片選有 UW2.EXE 的目錄。）
   c. 「配樂」選配樂方式：
        soundfont：內建，不需要其他檔案（預設）
        opl：Sound Blaster／AdLib 的原版 FM 配樂
        mt32、cm32l：需要 MT-32 ROM（見下一節）
      不論選哪種，音效都用 Sound Blaster 的音效（UW1 是 FM 合成，UW2 是數位音效）。
   d. 「美術」選「原版(低像素風格)」。想要高清畫面時，在下方選 2 倍或 4 倍，按「產生像素高清素材」
      （用你自己的遊戲檔案在這台電腦產生，大約一分鐘），完成後美術會自動切換成「像素高清」。
      素材放在程式旁邊的 HD 資料夾，和 ROMS 放在一起；刪掉 HD 就回到原版美術。
   e. 「視窗大小」選視窗大小或全螢幕。
4. 按遊戲卡片下方的「開始遊戲」（或點封面）。


五、MT-32 配樂（選用）
----------------------

1. MT-32 或 CM-32L 的 ROM 需要自備，本程式不附。
2. 把 ROM 檔放進程式資料夾裡的 ROMS 資料夾，例如：
     ROMS\MT32_CONTROL.ROM
     ROMS\MT32_PCM.ROM
   （也接受 CM32L_CONTROL.ROM、CM32L_PCM.ROM 與 MAME 格式的檔名。）
   或在啟動畫面（配樂選 mt32／cm32l 時）的「MT-32／CM-32L ROM 目錄」按「瀏覽…」改選其他資料夾。
3. 啟動畫面的 ROM 欄位下方出現綠色的「已找到 MT-32 ROM」後，「配樂」選 mt32 或 cm32l。
4. 記得先安裝第一節的 Visual C++ 可轉散發套件。


六、常見問題
------------

- 設定檔位置：%APPDATA%\Godot\app_userdata\Underworld\settings.json
  設定亂掉時，關閉遊戲後刪除這個檔案，下次啟動會恢復預設。
- 沒有中文：確認啟動畫面的 Language 選了「繁體中文」，以及程式資料夾裡有 i18n 資料夾。
- 沒有聲音：確認遊戲目錄裡有 SOUND 資料夾。
- 存檔失敗：遊戲目錄是唯讀的，照「二、準備遊戲檔案」步驟 3e 取消唯讀。
- 玩家輸入（對話中輸入的關鍵字、祭壇咒語、存檔說明）只能輸入英文。
