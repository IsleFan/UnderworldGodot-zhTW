UnderworldGodot-zhTW 安裝說明（Windows）
==========================================

《Ultima Underworld》（創世紀地下世界）的 Godot 重製引擎，含繁體中文化。
本程式不含遊戲資料，需要你自己合法擁有的遊戲檔案（例如 GOG 版）。
本程式不需要安裝：解壓縮後照下面的順序做即可。

系統需求
--------
- Windows 10 或 11，64 位元（x64）
- 支援 Vulkan 或 DirectX 12 的顯示卡與驅動程式（近年的顯示卡與內建顯示晶片都支援）
  Parallels 等虛擬機的虛擬顯示卡不支援，請在實體電腦上執行。
- 不需要安裝 .NET、Godot 或其他執行環境，已經包含在程式裡


需要自行準備的東西
------------------

必要：
1. 遊戲本體：GOG 的《Ultima Underworld 1+2》（https://www.gog.com），用 GOG Galaxy 或離線安裝程式裝好。
   一代與二代附的是同一張遊戲光碟映像，裝其中一個就有兩代。

選用（只有想聽 MT-32 配樂才需要）：
2. Microsoft Visual C++ 可轉散發套件（x64），微軟官方下載：
     https://aka.ms/vs/17/release/vc_redist.x64.exe
   執行後勾選同意授權條款，按「安裝」，不需要重新開機。很多電腦已經裝過，重複安裝也沒關係。
   沒裝時選 MT-32 配樂會自動改用 OPL 配樂，其他功能完全不受影響。
3. MT-32 或 CM-32L 的 ROM 檔：有版權，本程式不附，需自備（見「MT-32 配樂」）。

建議：
4. 顯示卡驅動程式更新到最新版（NVIDIA、AMD、Intel 官網）。畫面全黑或打不開時先更新驅動。


安裝與第一次啟動（照順序）
--------------------------

步驟 1　安裝遊戲本體
  在 GOG 安裝好《Ultima Underworld》或《Ultima Underworld II》。不用自己取出遊戲檔案：
  本程式的啟動畫面會自動找到 GOG 的安裝，並把兩代遊戲取出到程式旁邊。

步驟 2　（選用）安裝 Visual C++ 可轉散發套件
  想聽 MT-32 配樂才需要，見上面「需要自行準備的東西」第 2 項。

步驟 3　解壓縮本程式
  a.（建議）在下載的 zip 上按右鍵 >「內容」，在下方勾選「解除封鎖」> 確定。
     這樣解壓縮出來的程式不會再被 Windows 擋下。
  b. 把 zip 解壓縮到你可以寫入的資料夾，例如 C:\Games\UnderworldGodot-zhTW 或「文件」裡。
     不要放在 Program Files：遊戲檔案、存檔與高清素材都會放在程式旁邊，那裡無法寫入。
  c. 整個資料夾一起保留：Underworld.exe 旁邊的 Underworld.pck、data_Underworld_windows_x86_64、
     i18n、soundfonts、ROMS 都是程式需要的。

步驟 4　打開程式
  按兩下 Underworld.exe。如果出現藍色的「Windows 已保護您的電腦」（本程式沒有數位簽章），
  按「其他資訊」>「仍要執行」。這個畫面只會出現在第一次。

步驟 5　在啟動畫面依序設定
  a. 語言：右上「Settings」的「Language」選「繁體中文」，整個畫面會換成中文（之後會記住）。
  b. 遊戲目錄：啟動畫面一打開就會自動尋找遊戲，依序找：
       程式旁邊的 UW1、UW2 資料夾 → 舊版一鍵安裝的 %USERPROFILE%\Games\UWGOG → GOG 的安裝
     只找到 GOG 的光碟映像（game.gog）時，會自動把兩代遊戲取出到程式旁的 UW1、UW2（約數秒）。
     兩張遊戲卡片下方出現綠色「已找到遊戲」就完成了。
     顯示「沒有找到遊戲目錄」時，按該卡片的「瀏覽…」，選有 UW.EXE（二代是 UW2.EXE）、
     DATA、SOUND 的資料夾；或照「找不到遊戲時」手動取出。
  c. 操作：「原版操作」照原版的方式；「優化操作」可用左鍵自動判斷說話／撿取／使用、右鍵查看、
     Tab 滑鼠視角、X 拔刀等，並可調整滑鼠速度、上下反轉與按鍵（「按鍵設定…」）。
  d. 配樂：
       soundfont：內建，不需要其他檔案（預設）
       opl：Sound Blaster／AdLib 的原版 FM 配樂
       mt32、cm32l：需要 MT-32 ROM 與 Visual C++ 可轉散發套件（見「MT-32 配樂」）
     不論選哪種，音效都用 Sound Blaster 的音效。
  e. 美術：先用「原版(低像素風格)」即可。想要高清畫面時，在下方選 2、4 或 8 倍
     （8 倍約佔 1 GB），按「產生像素高清素材」（用你自己的遊戲檔案在這台電腦產生，約一分鐘），
     完成後「美術」會自動切換成「像素高清」。素材放在程式旁的 HD 資料夾，刪掉 HD 就回到原版美術。
  f. 視窗大小：選視窗大小或全螢幕。
  g. 按遊戲卡片下方的「開始遊戲」（或點封面）。

  以上設定都會記住，之後只要按兩下 Underworld.exe，再按「開始遊戲」。


找不到遊戲時（手動取出遊戲檔案）
--------------------------------

需要的是一個同時含有 UW.EXE、DATA 資料夾、SOUND 資料夾的「遊戲目錄」。

1. 打開 GOG 的遊戲安裝資料夾（GOG Galaxy：在遊戲頁面按「管理安裝 > 顯示資料夾」）。
   - 如果資料夾裡已經有 UW.EXE、DATA、SOUND，直接在啟動畫面按「瀏覽…」選這個資料夾。
   - GOG 版通常把遊戲包在一個叫 game.gog 的光碟映像檔裡，請繼續步驟 2。
2. 把 game.gog 複製一份到桌面，改名成 game.iso。
   （看不到副檔名時：檔案總管 > 檢視 > 勾選「副檔名」。）
3. 在 game.iso 上按兩下，Windows 會把它掛載成一個光碟機。
4. 光碟裡的 UW 資料夾是第一代，UW2 資料夾是第二代。把它們複製到本程式資料夾裡，
   改名成 UW1、UW2（和 Underworld.exe 同一層），啟動畫面就會自動找到。
5. 複製完成後，在檔案總管的光碟機上按右鍵 >「退出」，再刪除桌面上的 game.iso。
6. 從光碟複製出來的檔案可能是唯讀的，這樣會沒辦法存檔：
   在 UW1（及 UW2）資料夾上按右鍵 > 內容 > 取消勾選「唯讀」> 套用 >
   選「將變更套用至此資料夾、子資料夾及檔案」> 確定。


MT-32 配樂（選用）
------------------

1. 先安裝 Visual C++ 可轉散發套件（見「需要自行準備的東西」第 2 項）。
2. 把自備的 ROM 檔放進程式資料夾裡的 ROMS 資料夾，例如：
     ROMS\MT32_CONTROL.ROM
     ROMS\MT32_PCM.ROM
   （也接受 CM32L_CONTROL.ROM、CM32L_PCM.ROM 與 MAME 格式的檔名。）
   或在啟動畫面（配樂選 mt32／cm32l 時）的「MT-32／CM-32L ROM 目錄」按「瀏覽…」改選其他資料夾。
3. 啟動畫面的 ROM 欄位下方出現綠色的「已找到 MT-32 ROM」後，「配樂」選 mt32 或 cm32l。


常見問題
--------

- 設定檔位置：%APPDATA%\Godot\app_userdata\Underworld\settings.json
  設定亂掉時，關閉遊戲後刪除這個檔案，下次啟動會恢復預設。
- 畫面全黑幾秒後就關閉：先更新顯示卡驅動程式。在虛擬機（例如 Parallels）裡無法執行。
- 沒有中文：確認啟動畫面的 Language 選了「繁體中文」，以及程式資料夾裡有 i18n 資料夾。
- 沒有聲音：確認遊戲目錄裡有 SOUND 資料夾。
- 存檔失敗：遊戲目錄是唯讀的，照「找不到遊戲時」步驟 6 取消唯讀。
- 玩家輸入（對話中輸入的關鍵字、祭壇咒語、存檔說明）只能輸入英文。
